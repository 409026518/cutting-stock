# 下料计算器 (Cutting Stock Calculator)

一维下料优化工具，专为铁艺栏杆等管材加工场景设计。给定一根原料长度（默认 6m）和多种定长零件需求，自动求出**最少需要购买多少根原料钢管**，并给出每种最优裁剪方案。

## 功能
- **最优下料**：基于列生成 + 分支定价（Branch-and-Price）求整数最优解，非近似
- **锯缝损耗**：可配置每刀毫米数，计算时自动扣减
- **余料处理**：按废料计（不跨订单复用）
- **导出**：Excel（真实 .xlsx，纯前端离线生成）、打印下料单、PDF 报告、逐根编号清单（可勾选标记已切）

## 使用方法
直接用浏览器打开 `下料计算器.html` 即可，**无需联网、无需安装、无需服务器**。

## 算法说明
求解器在浏览器端纯 JavaScript 实现，针对一维下料问题（Cutting Stock Problem）：
- 整数规划松弛 + 两阶段单纯形法
- 列生成（Gilmore-Gomory）动态生成裁剪图案
- 分支定价（Branch-and-Price）+ 安全剪枝求整数最优
- 小规格场景采用全图案枚举，保证结果精确

### 示例验证
需求：1.3m×60 根、0.9m×122 根、0.24m×521 根，原料 6m，锯缝 0。
结果：**最少 53 根**，利用率 **98.4%**，已验证为整数最优。

算法正确性已用 Python（pulp）精确解对 40 个随机算例逐一比对，结果完全一致。
